# Mini Projects

这个目录用于把零散知识组合成可运行的小项目。

项目规模不必大，重点是训练从需求到实现的完整过程，并逐渐形成实习中可展示、可解释的工程代码。

## 合适的项目类型

例如：

- 数据清洗与分析脚本
- 命令行工具
- 模型训练与评估小项目
- 简单分类 / 回归服务
- 批量文件处理工具
- API 数据采集与异步请求工具
- 小型 PyTorch 训练项目
- ML 推理 API

## 每个项目优先体现

- 清楚的目录结构；
- README 与运行方法；
- 环境 / 依赖说明；
- 配置与日志；
- 异常处理；
- 合理的函数和模块拆分；
- 基本测试；
- 可复现的输入输出；
- 对关键技术选择的解释。

不追求为了“项目数量”制造大量模板工程。每个项目都应至少承担一个明确的学习目标。
