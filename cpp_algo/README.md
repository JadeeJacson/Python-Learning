# C++ Algorithm Practice

这个目录用于把典型算法题作为 C++ 的持续编码训练场。

已有 Python 题目仍保留在 `py_algo/`，不迁移、不批量复制。

## 默认训练方式

对于值得反复掌握的典型题：

1. 先确认自己理解算法模式；
2. Python 独立实现或复盘已有实现；
3. 分析时间复杂度与空间复杂度；
4. 间隔后使用 C++ 独立重写；
5. 比较 Python 与 C++ 的容器、类型、边界处理和实现细节。

## 重点算法模式

- 数组 / 哈希
- 双指针
- 滑动窗口
- 二分
- 栈 / 队列
- 链表
- 树
- 堆 / priority_queue
- 图
- DFS / BFS
- 回溯
- 贪心
- 动态规划

## 重点 STL

算法训练中逐步熟悉：

- `vector`
- `string`
- `unordered_map` / `map`
- `unordered_set` / `set`
- `stack`
- `queue`
- `deque`
- `priority_queue`
- `sort`
- `lower_bound` / `upper_bound`
- iterator

不要求把 `py_algo/` 的每一道旧题机械地翻译成 C++。优先选择具有代表性的题目重新独立完成。
